# AyuGram iOS (рабочее название)

Мод поверх официального [Telegram-iOS](https://github.com/TelegramMessenger/Telegram-iOS).
Все свежие фичи телеги (GRAM-кошелёк, публикации в профиле и т.д.) приходят из апстрима,
поверх них накладываются наши правки.

Репозиторий не хранит весь код телеги. В нём только:

| Путь | Что это |
|---|---|
| `UPSTREAM_REF` | коммит Telegram-iOS, на который накладываем мод |
| `ayu/apply.py` | накладывает правки на код телеги (с проверкой, что всё совпало) |
| `ayu/files/` | наши новые файлы, копируются в дерево телеги |
| `.github/workflows/build.yml` | сборка `.ipa` на маке GitHub Actions |

## Что уже есть

**Режим призрака** — Настройки → Конфиденциальность → самый верх, переключатель «Режим призрака».
Когда включён, не отправляются:
- «прочитано» (у собеседника остаются одна галочка);
- «в сети» (всегда шлём «не в сети»);
- «печатает…», «записывает голосовое» и т.п.;
- просмотры историй.

**Значки exteraGram / AyuGram** — у разработчиков, саппортеров и их каналов рядом с именем
(в профиле и в списке чатов) показывается значок, как в AyuGram. Список берётся из того же
публичного JSON, что грузят их клиенты (`update.ayugram.one`, запасной — `api.exteragram.app`),
кэшируется и обновляется раз в час. Кастомные значки (эмодзи) показываются как есть.
Код: `ayu/files/.../AyuBadges.swift` и `AyuBadgeContent.swift`.

Ограничения v1: при отправке сообщения сервер всё равно на минуту покажет «в сети»;
комментарии/топики форумов пока могут отмечаться прочитанными.

## Как собрать (без Мака)

1. **GitHub.** Создай **публичный** репозиторий (для публичных macOS-сборки бесплатны,
   а лицензия GPL всё равно требует открыть код) и залей туда эту папку.
2. **API-ключи.** Зайди на https://my.telegram.org → API development tools → создай приложение.
   В репозитории: Settings → Secrets and variables → Actions → New repository secret:
   - `TG_API_ID` — api_id
   - `TG_API_HASH` — api_hash
3. **Сборка.** Вкладка Actions → «Build IPA» → Run workflow. Идёт 1.5–3 часа.
   Готовый `.ipa` появится в Releases (и в артефактах сборки).
4. **Установка на айфон** — через [Sideloadly](https://sideloadly.io) (Windows) или SideStore,
   с обычным Apple ID. С бесплатным Apple ID:
   - включи опцию удаления расширений (Remove app extensions), иначе упрёшься в лимит App ID;
   - приложение живёт 7 дней, потом переподписать.

## Важно знать

- **Пуш-уведомления не будут приходить.** Пуши телеги привязаны к официальному приложению;
  у самосборки их нет. Сообщения приходят, когда приложение открыто.
- Код кошелька не трогаем — он работает как в официальном клиенте.
- Не называй приложение «Telegram» и не ставь их иконку, если будешь кому-то раздавать.

## Обновление до новой версии телеги

Поменять коммит в `UPSTREAM_REF` на свежий с
https://github.com/TelegramMessenger/Telegram-iOS/commits/master и запустить сборку.
Если upstream поменял код в местах наших правок, сборка упадёт на шаге «Apply mod»
с названием правки, которую надо поправить в `ayu/apply.py`.
